# IJYE website

Responsive static website for the International Journal of Youth Engineering.

- `index.html` — homepage
- `Journal/index.html` — article archive
- `Submit/index.html` — submission page with an embedded Tally form
- `terms.html` and `privacy.html` — terms of service and privacy policy
- `assets/styles.css` — shared styling and responsive layouts
- `assets/app.js` — mobile navigation
- `assets/ijye-robotic-claw-blueprint.png` — homepage illustration

## Test locally
Run `python -m http.server 8000` from this directory and open `http://localhost:8000`.

The submission form is hosted by Tally. Review the policy pages regularly and keep their descriptions aligned with the live form, data handling, and publication practices.
